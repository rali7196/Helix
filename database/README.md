# The Database

This is the database for the application. It's pretty simple to set up, all you need
to do is run the setup.sh script in the scripts directory, from the database directory. e.g., your current working directory should be in the database directory. Before this however, you also need to have docker compose setup on your computer, including having it be able to run without sudo. See the docker documentation [here](https://docs.docker.com/desktop/setup/install/linux/ubuntu/) for more information about this.
