# Web App

## What is it?

This is the frontend for the main web application. It is a react app that runs on vite.

## How to set it up?

First, you need to install node version manager and install node 22.14. You can do that with the 
following commands:

```
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.1/install.sh | bash
nvm install 22.14
nvm use 22.14
```

After that, navigate to the web_app directory in your terminal and install all the dependencies with 
this command

```
npm i
```

Finally, you can run the web app by runnnig this command

```
npm run dev
```

There, it should give you a link to navigate to in your browser.
