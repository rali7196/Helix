# Helix

This is my submission for the take home project for Sellscale.ai. Please look at the README files in the
web_app, database, and api_service_proj directories for information on how to set them up. Note that the instructions are meant for a unix machine. i.e., Ubuntu 22.04 or MacOS

# Planned Features

## LinkedIn Integration
Recruiters can paste in a candidate's linkedin profile to the agent, and the agent would be able to draw information from the candidate's file. However, it looked like you need to be a legitimate business and go through a lengthy approval process with LinkedIn to do this.

## Resume upload
Recruiters should be able to upload a candidate's resume, since this is normally publically posted on their profile,
and the agent should be able to figure out how to best create a recruiting sequence for them.
